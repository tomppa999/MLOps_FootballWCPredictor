Only `poisson_glm` gets new forecasts and tournament simulations. The command reuses the other models’ archived predictions and entropy values and reruns the statistical comparisons that consume them.

Keep the three-seed experiment as a sensitivity analysis. Its seed ranges measure Monte Carlo variability. Official intervals and tests come from the existing paired analysis.

## 4. Compute the corrected Poisson forecasts

1. Recover the three rates from the historical scaler and coefficients using the fitted model’s feature order, intercept and clipping. Check that `λ1 + λ3` and `λ2 + λ3` reproduce the archived, correctly oriented goal means for every match and logged pairing. Use an absolute tolerance justified by stored precision, record the worst key and error, and report the synthetic exceptions separately. The trial’s maximum error on logged cycles was approximately `3.55e-15`.
2. For RQ1/RQ3 compute home/draw/away from the difference of independent Poisson variables with rates `λ1` and `λ2`. The shared draw cancels in the difference. Use exact Skellam probabilities in the existing home/draw/away order, with explicit handling of zero-rate limits. The old scorer also truncated and renormalized a 0–10 grid. Quantify that numerical difference once by comparing the archived independent grid with exact independent probabilities at the same marginal means. This distinguishes the grid effect from the dependence correction.
3. For RQ2 use the existing tournament engine with an explicit joint sampling option. Draw independent `X1, X2, X3` with the three component rates and return `(X1 + X3, X2 + X3)` for each simulated match. Apply this to groups, knockout regulation time and extra time. Extra time uses a fresh draw with **all three** rates scaled by `30/90`. Preserve host/venue selection, tie-breaks, penalties and result locking. Carry the shared rate from the selected orientation when reversing the sides. Validate joint-rate coverage for every reachable pairing.
4. Keep one bracket implementation. Add the smallest backward-compatible entry point for the corrected analysis and regression-test the original two-rate path with its original seed and draw order. Use the trial engines as test references. Key any simulation reuse on all effective inputs, including oriented rates, locks, tournament configuration, seed and simulation count.
